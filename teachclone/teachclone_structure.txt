  ┌────────────────────────────────────────────────────────────┐
  │  📦  teachclone                                             │
  │  Type: ROOT                                                 │
  └────────────────────────────────────────────────────────────┘
    Monorepo root. Managed with pnpm workspaces. Contains two apps (web +
    api) and shared packages. Run everything from here.
    Key points:
      •  pnpm install — installs all workspace deps
      •  pnpm dev — starts both web and api in parallel
      •  docker compose up — starts Postgres, Redis, Qdrant, API, Worker, Web
    Structure / Example:
        teachclone/
        ├── apps/           ← web + api apps
        ├── packages/       ← shared types + config
        ├── docker/         ← compose + Dockerfiles
        ├── .github/        ← CI/CD workflows
        ├── scripts/        ← dev utility scripts
        └── docs/           ← architecture docs

      Next.js 14 frontend with App Router. TypeScript, Tailwind CSS,
      shadcn/ui. Deployed to Vercel.
      Key points:
        •  App Router with route groups: (auth) and (protected)
        •  Clerk for authentication + middleware
        •  Vercel AI SDK for streaming chat
        •  Zustand + React Query for state management
      Tech stack:  Next.js 14 | TypeScript | Tailwind CSS | shadcn/ui | Clerk | Stripe | Vercel AI SDK

        ┌────────────────────────────────────────────────────────────┐
        │  🔌  apps/web/lib/api-client.ts                             │
        │  Type: TS FILE                                              │
        └────────────────────────────────────────────────────────────┘
          Typed API client. Axios instance preconfigured with base URL, auth
          interceptor (attaches Clerk JWT), and error normalization.
          Key points:
            •  Base URL: process.env.NEXT_PUBLIC_API_URL
            •  Request interceptor: await clerk.session?.getToken() → Bearer header
            •  Response interceptor: maps errors to { message, code, status }
            •  Exports typed functions: getMe(), syncUser(), getProfiles(), etc.
          Structure / Example:
              // Usage
              import api from '@/lib/api-client'
              const profiles = await api.get<TeacherProfile[]>('/teacher-profiles')

          ┌────────────────────────────────────────────────────────────┐
          │  🎭  apps/api/app/services/style_extractor.py               │
          │  Type: PY FILE                                              │
          └────────────────────────────────────────────────────────────┘
            Extracts a structured StyleProfile from transcript chunks. Combines
            statistical NLP analysis with LLM classification.
            Key points:
              •  Flesch-Kincaid grade level via textstat library
              •  Analogy density: regex search for "like","imagine","think of","similar to"
              •  Signature phrase extraction: Counter on 3-5 word n-grams
              •  LLM analysis via Claude: tone_type, explanation_pattern, pacing
              •  Averaging: if teacher has multiple videos, profiles are averaged
            Structure / Example:
                class StyleExtractor:
                  async def extract(self, chunks) -> StyleProfile:
                    text = join(chunks)
                    stats = {
                      vocabulary_score: flesch_kincaid(text),    # textstat
                      avg_sentence_length: nltk.sent_tokenize(),
                      analogy_density: regex_count(ANALOGY_WORDS),
                      signature_phrases: top_ngrams(text, n=3-5)
                    }
                    llm = await self._llm_analyze(chunks[:15])   # Claude
                    return StyleProfile(**stats, **llm)

                async def hybrid_search(query_dense, query_sparse, teacher_profile_id, top_k=8):
                  dense_results = await client.search(
                    collection_name=COLLECTION,
                    query_vector=query_dense,
                    query_filter=Filter(must=[FieldCondition(key="teacher_profile_id"...)])
                  )
                  sparse_results = await client.search(using="sparse", ...)
                  return rrf_merge(dense_results, sparse_results, k=60)[:top_k]
