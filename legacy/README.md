# Legacy Prototype (Archived)

> **ARCHIVED & NOT MAINTAINED — SEE [teachclone/](../teachclone/)**

This directory contains the original desktop / local proof-of-concept prototype (`backend/`, `frontend/`, `electron/`).

It has been superseded by the production SaaS application located in **[`teachclone/`](../teachclone/)**:
- **Backend API**: `teachclone/apps/api` (FastAPI, 7-layer Teacher DNA, local Ollama LLM provider, hybrid vector search, SM-2 spaced repetition).
- **Web App**: `teachclone/apps/web` (Next.js 14, TypeScript, Tailwind CSS).
- **Deployment**: `teachclone/docker-compose.yml`.

Do not add new features or bug fixes to this legacy directory. All active development takes place in `teachclone/`.
